02 — About

A bit about me

I'm a young app developer — curious, stubborn in the useful way, and genuinely interested in how an app feels as much as how it's built. I completed an IFTS programme focused on developing for Apple devices with Swift and Xcode, and I work with Flutter for cross-platform builds.

What I enjoy most is turning an idea into something real: sketching the interface in Figma, then writing the code that makes it behave. I've taken an app all the way to the App Store, and I've wired up analytics with Google Tag Manager to understand what people actually do once they're inside.

03 — Services

What I can do for you

Five things I'm set up to take on, from the first sketch to the day it's live in front of users.

iOS App Development

Native apps written in Swift, built with SwiftUI or UIKit depending on what the project actually needs. From an empty Xcode project through to a build that's ready for review.

Web Development

Responsive websites and web interfaces built with HTML, CSS and JavaScript. Clean markup, quick loading, and layouts that hold up from a phone screen to a wide desktop monitor.

Cross-Platform Apps

One Flutter codebase running on both iOS and Android — the sensible route when a project needs to reach everyone without paying to build the same thing twice.

App Interface Design

Screens and flows designed in Figma, prototyped so you can click through them before a line of code exists. Handed over in a state a developer can actually build from.

Launch & Analytics

Getting the app through App Store Connect and out the door, then wiring up Firebase and Google Tag Manager so you can see what people do once they're inside it.

Something close to this but not quite it? Tell me what you need — happy to talk it through.
